# 語音控制記分板

用聲音控制的球類記分板 MVP，支援羽球、桌球、壁球、網球的單打／雙打計分，可用語音喊「藍隊加一分」「紅隊扣一分」操作，並會語音報分。

## 使用方式

純前端網頁，開啟 `index.html` 即可（建議部署到 GitHub Pages，語音辨識需要 HTTPS）。

1. 選球類、單打/雙打、兩隊顏色 → 開始比賽
2. 用畫面上的加一分/扣一分按鈕手動記分，或開啟「收音模式」用語音記分
3. 語音指令格式：「{顏色}隊加一分」「{顏色}隊扣一分」（顏色：紅、藍、綠、黃、橘、紫）
4. 算錯分時可用「復原上一步」還原到上一個動作

## 已知限制

- 語音辨識在 iOS Safari／iPhone 上無法真正背景常駐聆聽，需保持螢幕開啟且分頁在前景，中斷後會自動嘗試重新啟動
- 不追蹤雙打發球輪替，只做比分與換邊提示
- 無帳號、無歷史紀錄、不支援多場同時進行

## 技術

純 HTML/CSS/JavaScript（ES modules），無建置工具。語音辨識使用瀏覽器內建 `SpeechRecognition`，語音回饋使用 `speechSynthesis`。
